Put your .wav files here.

30 coin sounds (one plays on every puck, about 8 seconds each):
  coin1.wav  coin2.wav  ...  coin30.wav
13 character sounds (play with each character's 15-puck pop-up):
  name1.wav  name2.wav  ...  name13.wav

After adding a file, open config.js and replace "insert wav" with its path, e.g. "sounds/coin1.wav".
Only .wav files are accepted. This file only exists so GitHub keeps the empty folder - you can leave it.
